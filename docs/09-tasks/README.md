# Implementation Tasks

> **Status:** PLANNED

Đây là tầng cuối cùng.

Chỉ tạo task khi Architecture → Flows → Components → Data Model → API/UI/Test đã đủ rõ.

Mỗi task phải có:
- objective;
- dependencies;
- exact scope/files;
- input/output contract;
- allowed/forbidden changes;
- tests;
- acceptance criteria;
- rollback.
